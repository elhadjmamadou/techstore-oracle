# 11 - Soutenance

Ce dossier contient les livrables de presentation du projet TechStore.

## Fichiers

- `presentation_TechStore.pptx` : support de soutenance.
- `scenario_demo.md` : scenario oral et ordre de demonstration.
- `demo_finale.sql` : script SQL de demonstration a executer avec l'utilisateur `TECHSTORE`.

## Ordre d'utilisation

1. Ouvrir la presentation PowerPoint.
2. Suivre le scenario de demonstration.
3. Executer `demo_finale.sql` dans DataGrip ou SQL*Plus.
4. Montrer les captures pour les parties RMAN et reseau si l'execution en direct n'est pas possible.
